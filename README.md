# openpeon-balatro

A [peon-ping](https://github.com/PeonPing/peon-ping) sound pack themed around [Balatro](https://www.playbalatro.com/).

## Install

Once registered in the OpenPeon registry:

```bash
peon packs install balatro
peon packs use balatro
```

Or install directly from this repo for local testing:

```bash
peon packs install-local /path/to/openpeon-balatro
peon packs use balatro
```
