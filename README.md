# openpeon-balatro

A [peon-ping](https://github.com/PeonPing/peon-ping) sound pack themed around [Balatro](https://www.playbalatro.com/).

## Install

```bash
peon-ping install coleboren/openpeon-balatro
```

## Adding sounds

Drop `.mp3`, `.wav`, or `.ogg` files into `sounds/` and reference them in `openpeon.json`.
